# local.ai

Your office AI assistant, running locally on a dedicated server. All processing stays on your network — nothing is sent to the cloud.

## Getting Started

Open your browser and go to:

**http://ai.local**

That's it. Pick a model from the dropdown, type your question, and go.

## What You Can Do

- **Write emails and content** — Draft professional emails, blog posts, social media content
- **Work with documents** — Summarize PDFs, review contracts, extract key points
- **Spreadsheet help** — Analyze data, create formulas, generate reports
- **Research** — Deep-dive into topics with citations and structured output
- **Code and automation** — Generate scripts, debug code, automate repetitive tasks
- **Brainstorm** — Strategy sessions, business plans, marketing ideas

## Access From Any Device

| What | How |
|------|-----|
| Chat interface | http://ai.local |
| From Windows/Mac/Linux | Just open the URL in any browser |
| From phone/tablet | Same URL — works on mobile browsers too |

No installation needed on your computer. If `ai.local` doesn't load, use `http://192.168.29.100` instead.

## Tips

- **Be specific** — "Write a formal email to the client about the Q1 budget delay" works better than "write an email"
- **Give context** — Paste in the document or data you want analyzed
- **Iterate** — Ask follow-up questions to refine the output
- **Upload files** — Drag and drop files into the chat for analysis
